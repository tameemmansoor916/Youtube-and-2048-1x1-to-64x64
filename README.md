# 2048 Game - 64x64 Grid

A web-based implementation of the classic 2048 game with a 64x64 grid for an extreme challenge!

## Features

- **64x64 Grid**: Massive gameplay area with 4,096 tiles
- **Smooth Animations**: Tiles appear with smooth transitions
- **Score Tracking**: Keep track of your score as you play
- **Responsive Design**: Works on desktop and mobile devices
- **Keyboard Controls**: Use arrow keys or WASD to move tiles

## How to Play

1. Open `index.html` in your web browser
2. Use the following controls to move tiles:
   - **Arrow Keys**: Up, Down, Left, Right
   - **WASD**: Alternative control scheme
3. Combine tiles with the same number to create larger numbers
4. Reach the 2048 tile (or beyond!) to win
5. Click "New Game" to start over

## Game Rules

- Two tiles with the same number merge into one tile with double the value
- Your score increases by the value of the merged tile
- After each move, a new tile (2 or 4) appears randomly
- The game is over when no more moves are possible
- You can continue playing after reaching 2048 to achieve a higher score
